# 11 页面规格

每页都沿用现有函数的数据，只重排版式和状态。字段名与 `defaultDraft`、`saveLocalEntity` 的 payload 一致。组件外观见 `14-component-specifications.md`，宽度规则见 `15-responsive-layout.md`。

共同壳（主 Tab 内）：

- 顶：可选返回、标题、添加。首页用问候区代替普通标题。
- 中：可滚动内容。离线横幅贴在滚动区上方，关闭后本次会话不再出现（`lt_hide_banner`）。
- 底：六个 Tab。手机固定；宽屏改为侧栏后，底栏不重复出现。

## 1. 启动

对应 `index.html` `#boot-splash` 与 `boot()`。

全屏暖色底，居中 logo，一句「家庭待办 · 正在启动」。`boot` 结束调用 `hideBootSplash`。失败时已有「页面加载失败 / 重新加载」，保留。

不在闪屏上做进度百分比。原生 Splash 背景与这一屏同一颜色，避免先白后青。

| 落地 | |
| --- | --- |
| 文件 | `apps/web/index.html`，`capacitor.config.json` 的 Splash `backgroundColor` |
| 数据层 | 不影响 |
| 验证 | 冷启动能看见闪屏并进入登录或首页；`boot` 抛错时出现重新加载 |

## 2. 登录与注册

对应 `renderCloudLogin`、`renderCloudRegister`。Figma 登录 `46:54`。

结构：品牌字标、一句「把小日子，安排得刚刚好」、卡片表单。

登录字段：手机号、密码、协议勾选、主按钮「登录」。协议链接到 `./terms.html` 与 `./privacy.html`。注册字段：显示名（1–20）、手机号、密码、确认密码、协议、主按钮「注册并登录」。两次密码不一致时字段下错误，不跳转。

登录与注册互相链到对方。忘记密码是静态说明，不是按钮。

不放置验证码切换。`otpSend` 仍留在 `api.js`，页面不调用。

| 落地 | |
| --- | --- |
| 文件 | `apps/web/app.js` 两个 render；样式 `styles.js` |
| 数据层 | 不影响。仍调用 `api.login` / `api.register` |
| 验证 | 未勾选协议不能提交；注册成功且无家庭时进入家庭门；401 停留登录并 toast 服务端错误文案 |

## 3. 家庭门与合并

对应 `renderFamilyGate`、`renderMerge`。

家庭门两段，用分段控制而不是两个页面栈：创建（家庭名称）与加入（邀请码）。成功后若 `countGuestRecords() > 0` 进入合并，否则进首页。

合并页说明条数 `state.mergeCount`，两个动作：并入家庭、清空本机离线记录。清空走确认框，确认后才调用 `clearGuestData`。

| 落地 | |
| --- | --- |
| 文件 | `app.js` 对应函数 |
| 数据层 | 不改接口。并入仍是 `mergeLocalDataToFamily` |
| 验证 | 创建家庭后进入首页；有本地 `localOnly` 记录时先看到合并；清空需确认 |

## 4. 首页

对应 `renderHomeBody`。Figma `43:9`。

自上而下：

1. 问候：显示名、`fmtDateNice()`、头像（点按仍可进家庭 Tab）。
2. 搜索：只过滤本页的计划、待办、便签。占位「搜索计划、待办或便签…」。
3. 四格统计：未完成待办、进行中计划、今日日程、连续打卡。前三格跳到对应 Tab。连续打卡不跳转。天数算法保持现有「从今天往前数连续有完成打卡的日期」。
4. 洞察卡：有 `loadHomeInsight` 结果时显示完成率、第一张卡的标题和正文（最多约两行）、来源（AI / 规则兜底 / 规则）和时间。无结果时短文案加「去打卡」「打开洞察」。
5. 「我的项目」：最多 4 条未归档计划，点进详情。空则「创建第一个计划」。
6. 「今日待办」：最多 5 条未完成，行内可勾选。
7. 「最近便签」：最多 3 条，点进该条编辑，而不是只切到便签 Tab。

| 落地 | |
| --- | --- |
| 文件 | `app.js` `renderHomeBody`；日后可拆到 `screens/home.js` |
| 数据层 | 不影响。统计仍从 `listActive` 计算 |
| 验证 | 四格数字与列表条数一致；搜索不改待办页的搜索词；无计划、无待办、无便签时各段有空状态而不是整页空白 |

## 5. 待办

对应 `renderTodoBody`、`todoCard`。Figma `43:111`、新建 `46:328`。

本页搜索只匹配标题。筛选三枚：待办、今天、已完成，计数规则保持现有代码：未完成、截止日是今天或没有 `dueAt`、当前成员 `completions[id] === 'done'`。

行内容：勾选、标题、备注、截止或「今天」、优先级、执行人头像、待同步。点行打开编辑。勾选不打开编辑。

空状态按筛选和搜索词区分，文案沿用现在的三套（无待办 / 无完成 / 无匹配）。

| 落地 | |
| --- | --- |
| 文件 | `app.js` `renderTodoBody`、`todoCard`、`renderTodoForm` |
| 数据层 | 勾选仍写 `completions`。编辑保存同一 `id` |
| 验证 | 勾选后出现撤销；撤销后回到未完成；「今天」包含无截止日的未完成项；儿童可以勾自己的待办 |

## 6. 计划列表与详情

列表对应 `renderPlansBody`。Figma `43:345`。详情对应 `renderPlanDetail`。新建表单 Figma `49:588`。

列表筛选：全部、进行中、已归档。卡片显示标题、周期文案、打卡天数与次数、里程碑碎片、火花线。页底保留年热力 `yearHeatmapEl`。空列表给出「新建计划」。

详情：返回、标题、周期与提醒时刻、里程碑列表与进度、打卡按钮。里程碑可标完成并填写最多 200 字说明，说明进 `progressNote`。无归档按钮的现状要补上「归档」，写入已有 `archived`。

编辑使用与新建相同的字段，打开时填入该计划 payload。

| 落地 | |
| --- | --- |
| 文件 | `renderPlansBody`、`renderPlanDetail`、`renderPlanForm` |
| 数据层 | 更新同一计划 id。归档只改 `archived`。打卡仍新增 `checkin`。不新增表 |
| 验证 | 归档后默认首页不显示，列表「已归档」能看到；详情返回回到计划 Tab；儿童打不开新建计划 |

## 7. 日历

对应 `renderCalBody`。Figma `43:180`。

周一为首。月切换、选中日、今天。有事项的日期用类型色点（日程、待办、便签、打卡、里程碑），图例保留。

手机：月历可收起，下手势与按钮并存（`bindCalPull`、`lt_cal_expanded`）。宽屏：月历常驻，不依赖手势。

当日列表按时间排序。点计划或里程碑进计划详情；点便签、待办、日程打开对应编辑。空白日主按钮「新建日程」；儿童改为「新建待办」，因为儿童不能建日程。

| 落地 | |
| --- | --- |
| 文件 | `renderCalBody`、`styles.js` 日历段 |
| 数据层 | 不影响。聚合逻辑保持 |
| 验证 | 选中日与列表一致；五类图例都能点到已有目标；收起状态刷新后仍按 `lt_cal_expanded` 恢复 |

## 8. 便签

对应 `renderNotesBody`、`renderNoteForm`。Figma `43:292`。

搜索只匹配标题。置顶在前（`pinned`）。卡片显示标题、正文摘要、可见范围。动作：「编辑」「转待办」。点卡片等于编辑。

编辑字段：标题、正文、可见范围（仅自己 / 指定成员 / 全家）、指定成员（仅「指定成员」时）、置顶、附件。非家庭模式可见范围固定「仅自己」，与现在 `renderNoteForm` 一致。

| 落地 | |
| --- | --- |
| 文件 | `renderNotesBody`、`renderNoteForm` |
| 数据层 | 编辑同一 id。转待办新增 `todo`，不删除便签 |
| 验证 | 打开已有便签时标题不是空的；转待办后便签还在，待办 Tab 能看到同标题新待办 |

## 9. 家庭

对应 `renderMeBody`。Figma `43:424`。`state.tab` 使用 `family`。

区块顺序：

1. 身份：头像、显示名、角色、家庭名、手机号（有则显示）。家庭模式可换自己的头像。
2. 成员：人数、成员卡、邀请（管理员/家长）、添加儿童（管理员/家长）。
3. 共享待办：执行人多于一人，或执行人不是自己。最多 8 条，行内可勾选。
4. 动态：沿用现在的本地短句（打卡、完成待办、新便签），最多 6 条。这不是服务端 feed。
5. 设置与数据：立即同步、导出、冲突、注销、退出。显示最近同步时间（`kv.lastSyncAt`，已有写入）。不放推送开关，不放 AI 密钥。

洞察页里「到我的配置模型」改为「管理员在浏览器打开 /admin.html」。家庭页不嵌入运维表单。

| 落地 | |
| --- | --- |
| 文件 | `renderMeBody`、`tabs()` |
| 数据层 | 不影响。邀请 `createInvite`，儿童 `createChild`，头像 `uploadMedia purpose=avatar` |
| 验证 | 成人看不到邀请和添加儿童；管理员能复制邀请码；头像更新后成员列表刷新；退出后回到登录 |

## 10. 洞察（二级）

对应 `renderInsightsBody`、`loadHomeInsight`。

有家庭且接口成功：完成率、成员行、建议卡、管理员「手动刷新」。失败：说明加本机规则区（近 7 日打卡、待办建议、节奏提醒）。无数据：空状态，动作回首页。

返回回到进入前的 Tab（从首页来则回首页）。

| 落地 | |
| --- | --- |
| 文件 | `renderInsightsBody` |
| 数据层 | 只读 `/api/insights/latest`；管理员刷新 `POST /api/insights/run`。不改统计公式 |
| 验证 | 断网时仍能看到本机规则区；非管理员没有刷新按钮 |

## 11. 添加与四类表单

添加菜单对应 `renderCreateMenu`。表单对应 `renderNoteForm`、`renderTodoForm`、`renderEventForm`、`renderPlanForm`，外壳 `formShell`。

待办字段：标题、备注、截止、提醒（不提醒 / 截止时 / 提前 1 小时 / 自定义）、执行人、优先级（高/中/低）、附件。

日程字段：标题、全天、日期或开始结束、提醒（现有 `computeEventRemindAt` 的种类）、参与人、附件。默认日期用日历选中日。

计划字段：标题、说明、周期、每周则星期、每月则日期、间隔则天数、开始与结束、提醒时刻、执行人、里程碑、附件。

校验失败时错误出现在字段下，滚动到第一条错误。保存中按钮禁用并显示「保存中…」。

| 落地 | |
| --- | --- |
| 文件 | `app.js` 表单函数；`styles.js` `.form-screen` |
| 数据层 | 新建不传 id；编辑传现有 id。附件仍 `uploadMedia`，上限 9 个、20MB |
| 验证 | 儿童只有便签和待办；日历里新建日程带上选中日；保存失败 toast，草稿还在 |

## 12. 不进入本轮页面改造的表面

| 表面 | 原因 |
| --- | --- |
| `admin.html` | 运维页，密钥配置留在浏览器 |
| `privacy.html`、`terms.html` | 保留正文，不阻塞主流程 |
| `renderTodayBody`、本机账号、连接服务器三屏 | 无现行入口，不重做 |
| Android / iOS 小组件布局 | 快照合同不变；皮肤另排 |

法律页和运维页的数据层都不因本规格改动。
