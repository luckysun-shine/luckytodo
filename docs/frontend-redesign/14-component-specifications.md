# 14 组件规格

组件是规格名。代码里今天对应 `h()` 加上 `styles.js` 的 class，以及 `app.js` 里的函数。第一批不引入组件库。新建控件时仍用 `h()`，class 名沿用下表「现有 class」，避免两套命名。

数据层一览：除软删除和计划归档会写入已有字段外，这些组件本身不访问网络。读写仍由页面函数调用 `api.js`。

## 1. 按钮

现有 class：`.btn`、`.btn.secondary`、`.btn.ghost`、`.icon-btn`。

| 种类 | 外观 | 用途 |
| --- | --- | --- |
| 主按钮 | 底 `--accent`，字 `--on-accent`，高 `--tap`，圆角 `--radius-md` | 登录、保存、打卡、确认框的确认 |
| 次按钮 | 底 `--accent-soft`，字 `--accent-strong` | 空状态动作、次要跳转 |
| 幽灵按钮 | 透明，字 `--text`，描边 `--line` | 取消、返回旁的弱动作 |
| 图标按钮 | 44×44，圆角 14 | 返回、月份切换 |
| 文字按钮 | 无底，字 `--accent-strong` | Toast 里的撤销、链接式「全部」 |
| 危险按钮 | 底 `--miss`，字白 | 只放在确认框里：清空、注销、删除 |

禁用：不透明度 0.5，不改变布局。进行时把标签换成「保存中…」「生成中…」，并 `disabled`。按下缩放保持现有 `.fab:active` 一类的 0.96，主按钮同样。

最小点按宽度：主按钮在手机上通栏，在宽屏对话框里至少 160px。

| 落地 | |
| --- | --- |
| 文件 | `styles.js` |
| 数据层 | 不影响 |
| 验证 | 键盘焦点有 2px `--accent` 外环；禁用时点击不提交 |

## 2. 卡片

现有 class：`.card`、计划 `.project-card`、待办 `.todo-row`。

白底，圆角 `--radius-lg`，描边 `--line`，阴影 `--shadow`。内边距 `--space-4`。可点卡片加轻微按下态，整卡一个动作。行内如果还有勾选或「转待办」，这些按钮 `stopPropagation`，与今天便签「转待办」一致。

计划卡顶部可有 4px 柔和色条，用第 13 篇的四档低饱和色，不使用高饱和渐变。

待办行：左侧 24px 圆形勾选，完成时底 `--done`、标题中划线。右侧优先级是小字标签，不是色块墙。

| 落地 | |
| --- | --- |
| 文件 | `styles.js`、`todoCard`、计划卡片 |
| 数据层 | 不影响 |
| 验证 | 点勾选不打开编辑；点卡片打开编辑 |

## 3. 表单字段

现有 class：`.field`、`.field-password`、`.err`、`.check-list`。

标签在上，12px 等效字号，颜色 `--muted`。输入高 48px，圆角 `--radius-sm`，底 `--field`，无重描边。焦点：2px `--accent`。错误：边色 `--miss`，下方 `--text-xs` 错误句。

密码字段保留眼睛按钮（`authPasswordField`）。手机号 `inputmode=numeric`、`maxlength=11`。

选择执行人使用现有 `peoplePicker` 的按压行，选中描边 `--accent`。儿童看到的是「执行人是你自己」，不能改。

附件使用现有 `attachBlock`：缩略图加「+ 附件」。超过 9 个或 20MB 时 toast，不加入列表。

| 落地 | |
| --- | --- |
| 文件 | `styles.js`、`fieldEl`、`peoplePicker`、`attachBlock`、`authPasswordField` |
| 数据层 | 附件上传规则不变 |
| 验证 | 错误出现在字段下；密码可见切换不提交表单 |

## 4. 抽屉

现有 class：`.modal`、`.sheet`。用于添加菜单、邀请码、打卡、冲突选择。

手机：贴底，顶圆角 `--radius-xl`，最大高度 `min(88dvh, 720px)`，含拖动手柄。遮罩 `--overlay`。宽屏：改为居中对话框，宽度 `min(520px, calc(100% - 48px))`，四周圆角 `--radius-lg`，不再锁 430px。

打开后焦点进入抽屉内第一个控件。点遮罩关闭添加菜单和邀请码展示。打卡抽屉点遮罩等于取消，不保存。

| 落地 | |
| --- | --- |
| 文件 | `styles.js` `.modal` / `.sheet`；`renderCreateMenu` |
| 数据层 | 不影响 |
| 验证 | 手机贴底、宽屏居中；Escape 关闭菜单；打卡取消不产生 `checkin` |

## 5. 确认弹窗

今天是 `confirm` / `prompt`。新控件复用对话框外壳，角色 `alertdialog`。

结构：标题、一句后果、幽灵按钮「取消」、危险或主按钮确认。默认焦点在取消。确认才执行第 12 篇表格里的动作。

里程碑说明和儿童密码不再用系统 `prompt`，分别用打卡式的短字段和儿童表单。

| 落地 | |
| --- | --- |
| 文件 | 新的小型函数可放在 `app.js`，替换 `confirm` 调用点；`checkin.js` |
| 数据层 | 确认前后调用的 API 不变 |
| 验证 | 注销点取消后仍处于登录态；浏览器里不再弹出原生 confirm（这些流程） |

## 6. 空状态

现有 `emptyState`：图标、标题、说明、可选按钮。

图标用现有 `icons.clipboard` 线框，尺寸 40px，颜色 `--muted`，放在 `--accent-soft` 的 72px 圆角方块里。不画吉祥物，不放奖杯。

一页里可以有多段空状态（首页三段）。每段只有一个主动作。

| 落地 | |
| --- | --- |
| 文件 | `emptyState`、`styles.js` `.empty` |
| 数据层 | 不影响 |
| 验证 | 新账号首页三段空状态都有唯一按钮；搜索无结果没有创建按钮 |

## 7. 加载与错误

加载：按钮进行时，或洞察卡内一行文字。不使用全屏转圈遮罩，闪屏除外。

错误：

- 字段错误在字段下。
- 接口失败用 toast，保留用户已填内容。
- 洞察失败在卡片内说明，并展示本机规则，不把整页打成失败。
- 渲染崩溃保持现在的重新加载面板。

Toast：现有 `#toast`。位置在安全区之下。带动作时（撤销、去查看）高度容纳一行按钮，5 秒关闭；点动作立即关闭。同一时刻只保留最后一条。

| 落地 | |
| --- | --- |
| 文件 | `toast()`、`renderInsightsBody`、`styles.js` `.toast` |
| 数据层 | 不影响 |
| 验证 | 连续勾选两条时只显示最后一条撤销；撤销点按后该条回到未完成 |

## 8. 导航与头像

底栏现有 `.tabs`。六项：图标 22px，标签 `--text-xs`，选中色 `--accent-strong`，未选中 `--muted`。选中项底部 3px 圆点，不用整块色板。高度 `56px` 加安全区。当前为 FAB 留出的 `padding-right: 64px` 去掉，因为添加改到顶栏。

顶栏 `.top.appbar` 保持三列：返回或占位、标题、添加或头像。首页顶栏由问候区代替。

头像 `.avatar`：圆，无图时显示名字首字，底 `--accent-soft`。家庭页 86px 可编辑时右下角保留小笔。裁剪层 `.crop-mask` 行为保持：拖动、缩放、圆形导出 512 JPEG。

成员横排 `faceStack` 最多显示 3 个加「+N」。

| 落地 | |
| --- | --- |
| 文件 | `styles.js` `.tabs`、`.fab` 的使用位置、`avatarButton` |
| 数据层 | 头像仍 `purpose: 'avatar'` |
| 验证 | 360px 宽六字标签不换行、不横向滚动；添加按钮不盖住「家庭」 |

## 9. 日历与成长图形

日历格子、图例 class 保持 `cal-*`。选中日底 `--accent`、字白。今天用 `--accent` 描边。事项点直径 4px，颜色按类型映射到 `--accent`、`--warm`、`--done`、`--growth`、`--warn`，一种类型一色。

火花线与年热力只表示打卡密度。颜色阶梯来自 `--growth` / `--done`。图例写「打卡较少 / 较多」，不写分数或名次。

连续打卡在首页第四格，数字用 `--text-xl`，无数据时是「—」。

| 落地 | |
| --- | --- |
| 文件 | `styles.js` 日历与 `.hm-cell`；`sparklineEl`、`yearHeatmapEl` |
| 数据层 | 不影响 |
| 验证 | 无打卡时热力为空态而不是满格；色值来自变量 |

## 10. 离线横幅

现有 `.banner`。暖底 `--warm` 的 16% 混合，文字 `--text`，关闭按钮 44px。文案保持：「当前离线，改动会在联网后同步」。未加入家庭的横幅只应出现在家庭门，不在已进入主壳后重复；今天 `offlineBanner` 在无家庭时也会提示，主壳本身要求 `hasFamily()`，这条提示实际难出现。实现时不要为了横幅把未加入家庭的用户放进六 Tab。

| 落地 | |
| --- | --- |
| 文件 | `offlineBanner`、`styles.js` |
| 数据层 | 不影响。`sessionStorage` `lt_hide_banner` |
| 验证 | 断网出现横幅，关闭后本次会话不再出现，重新打开会话后离线仍出现 |
