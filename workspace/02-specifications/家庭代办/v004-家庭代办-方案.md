# 家庭代办 产品需求文档 v004（主屏组件）

状态：**implemented（工程已落地）**。本版相对 v003，交付 iPhone 主屏组件：今日提醒、家庭日历（液态玻璃视觉）、App Group 快照与组件内添加草稿。实现见 `ios/App/LuckyTodoWidget/`、`ios/App/Shared/`、`apps/web/src/widgetBridge.js`、`ios/WIDGETS.md`。真机验收仍依赖用户侧 Xcode 签名与 App Groups。

产品暂名 LuckyTodo。

## 1. 需求目标

在用户把 LuckyTodo 装到 iPhone 后，可从主屏幕添加桌面组件，不打开 App 也能看到家庭日程与今日提醒，并在日历组件上直接添加内容。

本版锁定三项：

1. **日历组件**：主屏日历界面可浏览当月/本周日程与待办落点，并支持在组件内直接添加内容（待办或日程）。
2. **今日提醒组件**：汇总「今天」将要提醒或已到点未处理的事项（待办提醒、日程提醒、计划打卡提醒）。
3. **液态玻璃 UI**：组件视觉贴近 Apple **液态玻璃（Liquid Glass）** 设计语言（目标对齐 iOS 26/27 主屏组件质感：半透明材质、柔和折射、细描边与系统字体层级），而不是沿用 App 内「夜航」实色卡片样式。

## 2. 背景与用户痛点

家庭日程和提醒如果只能进 App 才看得到，主屏利用率低。用户希望像系统日历、提醒事项那样，在桌面扫一眼，并在日历格子上随手记下事。

液态玻璃是系统级主屏组件的主流质感；若组件仍用深色实心块，会与系统桌面割裂。

## 3. 用户角色与核心场景

角色与权限沿用 v001–v003。组件只展示 **当前登录成员有权看见** 的数据；儿童账号组件不出现无权事项。

场景：

1. **扫一眼本周。** 林晨在主屏中号日历组件上看到周五「家长会」，点某一天空格，在组件交互里新建「接孩子」。
2. **出门前看提醒。** 周宁看小号「今日提醒」组件：20:00 阅读打卡、18:00 交电费；点一项可打开 App 详情（或组件内勾选完成，见 9.2）。
3. **换壁纸仍可读。** 组件使用液态玻璃材质，浅色/深色壁纸下文字对比度仍达标。

## 4. 需求范围

- WidgetKit 主屏组件（至少两种：日历、今日提醒）。
- 组件尺寸：见第 9 节（系统小号 / 中号 / 大号中选取支持的组合）。
- 日历组件内 **直接添加** 待办或日程（交互式组件）。
- 今日提醒组件展示今日提醒列表，支持点进 App 或有限的完成操作。
- 液态玻璃视觉规范（材质、字号、间距、亮暗适应）。
- 与主 App 本机库 / App Group 共享数据；联网后仍走 v003 同步队列。

## 5. 非目标范围（本规划版仍不做）

- 锁屏组件、待机显示、Apple Watch 复杂功能（可另开版本）。
- Android 桌面小部件。
- 在组件内上传附件、改头像、管理成员。
- 组件内完整月视图编辑器或拖拽改期（第一期以点选日期 + 简表单为准）。
- 强制依赖 App Store 小组件画廊以外的私有 API。

## 6. 产品架构

```text
主 App（含本机库 + 同步）
  └─ App Group 共享容器
        ├─ 只读快照：今日提醒、日历落点
        └─ 写入出口：组件新建的待办/日程 → 入主 App 同步队列
              │
              ▼
         Widget Extension
           ├─ 日历组件（可交互）
           └─ 今日提醒组件
```

全能签重签名后，小组件随 IPA 一起安装；扩展与主 App 必须同一 App Group 与同一签名团队。证书掉签时组件与主 App 一并不可用，重新签名安装后恢复。

## 7. 使用流程

### 7.1 添加组件

1. 长按主屏 → 编辑 → 添加组件 → 找到 LuckyTodo。
2. 可选「家庭日历」或「今日提醒」，选尺寸后放到主屏。
3. 首次若未登录：组件显示「打开 App 连接家庭」占位；登录并同步成功后自动刷新。

### 7.2 在日历组件上添加内容

1. 用户点选某一日期（或「今天」快捷）。
2. 组件展开简表单：标题（必填）、类型（待办 / 日程）、可选时间。
3. 保存后：本机立即出现在共享快照；主 App 下次活跃时纳入同步队列上传 NAS。
4. 无权限或未登录时：提示打开 App，不写入。

### 7.3 今日提醒

1. 组件按时间顺序列出今日提醒（最多按尺寸截断，余下显示「还有 N 项」）。
2. 点某一项：优先打开主 App 对应详情；若系统允许交互式 Toggle，待办可在组件内勾选完成（完成规则与 App 内一致，儿童不能代打卡）。

## 8. 产品风格：液态玻璃

组件 **不** 套用 App 内夜航实色皮肤，而遵循系统液态玻璃：

| 要素 | 要求 |
|------|------|
| 材质 | 半透明玻璃质感，随壁纸透色；支持系统亮/暗 |
| 形状 | 连续圆角，贴近系统组件半径；避免厚重描边卡片感 |
| 文字 | 系统 SF 体系；主标题清晰，次级信息降对比但仍可读 |
| 强调 | 少量系统着色或品牌色光点，不做大面积霓虹描边 |
| 动效 | 跟手、短促；添加成功用轻量反馈，不弹花哨动效 |
| 内容密度 | 小号少字；中号日历+当日摘要；大号月历或周历+列表 |

验收观感：把组件放在浅色与深色壁纸上截图，应接近系统「日历 / 提醒事项」组件的通透感，而不是独立深色 App 皮肤贴在桌面上。

## 9. 功能明细

### 9.1 日历组件

| 尺寸 | 内容 |
|------|------|
| 中号 | 本周条或迷你月历 + 当日 1–3 条事项 |
| 大号 | 月历落点（有事项的日期标记）+ 选中日列表；提供「添加」入口 |

规则：

- 落点来自有权看见的日程、有截止日的待办、计划发生日。
- **可直接添加**：交互入口明确（选中日后的 + 或空态按钮）。
- 添加字段最少：标题；类型默认待办，可切日程；日程需开始时间（默认选中日 09:00–10:00）。
- 创建人 / 执行人默认为当前登录成员。

### 9.2 今日提醒组件

| 尺寸 | 内容 |
|------|------|
| 小号 | 下一条提醒 + 今日剩余条数 |
| 中号 | 今日提醒列表 3–5 条 |
| 大号 | 今日提醒列表 6–8 条，可带完成勾选（若交互能力允许） |

排序：提醒触发时间升序；无具体时刻的计划提醒按设定钟点。已完成且不再需要提醒的不展示。

### 9.3 刷新与数据

- 时间线：系统 Timeline 刷新；主 App 同步成功或本机写入后主动 `reloadTimelines`。
- 离线：组件读 App Group 快照，不要求 NAS 在线。
- 隐私：组件不显示「仅自己」便签正文以外、且当前用户不可见的内容（与 v003 ACL 一致）。

## 10. 数据对象

复用 v003 本机实体；额外：

| 对象 | 说明 |
|------|------|
| WidgetSnapshot | 序列化后的今日提醒列表、日历落点摘要，写入 App Group |
| WidgetDraft | 组件内新建的草稿，写入后转成 todo/event 并入同步队列 |

## 11. 异常处理

| 场景 | 处理 |
|------|------|
| 未登录 / 会话过期 | 占位：「打开 LuckyTodo 登录」 |
| 无今日提醒 | 空态文案 + 可选「添加」跳进 App 或日历组件 |
| 全能签掉签 | 组件随 App 不可用；重装后需再同步一次生成快照 |
| 玻璃材质对比度不足 | 文字加适度材质背景或次级填充，保证可读 |
